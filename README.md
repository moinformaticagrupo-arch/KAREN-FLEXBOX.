# Práctico 1 – Maquetando con Flexbox | Pixel Lab

## Cómo abrirlo
1. Descomprimí el ZIP.
2. Abrí la carpeta `Practico1_Flexbox_V4`.
3. Hacé doble clic en `index.html`.

## Archivos incluidos
- `index.html`: estructura y contenido.
- `style.css`: diseño, Flexbox y adaptación responsive.
- `app.js`: interacción del menú.
- `README.md`: instrucciones.

## Aplicación de Flexbox
- `.nav`: alinea logo, navegación y botón.
- `.hero-grid`: organiza portada en dos columnas.
- `.stripe-inner`: distribuye los mensajes.
- `.service-list` y `.service`: ordenan y alinean servicios.
- `.gallery`: crea una galería con `flex-wrap` y `gap`.
- `.contact-row` y `.footer-row`: alinean los elementos finales.

## Publicar en GitHub Pages
1. Subí los archivos a la raíz de un repositorio.
2. Abrí Settings → Pages.
3. Elegí Deploy from a branch.
4. Seleccioná `main` y `/ (root)`.
5. Guardá y esperá el enlace de publicación.

Las imágenes y la fuente externas requieren conexión a Internet.
